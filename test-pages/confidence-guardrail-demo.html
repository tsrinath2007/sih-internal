80% Confidence Guardrail Active

In autonomous browser vision agents, guessing bounding boxes on blurry, degraded, or low-contrast text risks catastrophic PII leaks (e.g. leaking partial card digits or sending hallucinated tokens to cloud LLMs). Parallax enforces a strict 80% OCR Confidence Guardrail: any unstructured sensitive entity below 80.0% confidence automatically triggers a Fail-Safe Block (⚠️ BLOCKED), halting cloud transmission until verified.

< 80.0% Status: BLOCKED • Manual Review Required

🔒 Security Invariant 1 (Zero Silent Drops): Low-confidence PII is never silently discarded. Doing so would leave raw PII unredacted. Instead, Parallax retains candidate bounding boxes and triggers a fail-safe halt.
🧮 Security Invariant 2 (Mathematical Exception for Luhn Cards): Payment cards that satisfy the Luhn Mod-10 checksum ($O(n)$ verification) are mathematically authenticated, allowing relaxed thresholds down to 20% on metallic/embossed cards without false positives. Unstructured PII (email, phone, OTP, Aadhaar) strictly enforces the ≥ 80.0% threshold.
🌐 Security Invariant 3 (Zero-Leak Cloud Transmissions): Outgoing network payloads to cloud LLMs (Groq / Grok) contain 0 bytes of raw PII regardless of whether the scan status is READY or BLOCKED.
